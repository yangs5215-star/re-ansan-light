# RE:ANSAN 用光重新看见始华湖

## 光场版 v3

- 最多双手输入，每只手独立累积显色；使用左右手标识稳定追踪，避免两只手之间画出连接笔迹。
- 拇指与食指捏合时进入小范围蓝色聚光；张手为大范围绿色光圈。鼠标按住 Shift 可预览聚光。
- 停留时光圈能量缓慢增强；双手之间显示装饰性光线。上述粒子与光线为艺术效果。
- WebGL 光学后处理：局部水波折射、柔光、轻微颗粒与暗角；约30fps更新。无 WebGL 或上下文丢失则回退 Canvas；系统开启减少动态效果时不启用此层。
- 暂停/继续、空格暂停（按钮未聚焦时）；暂停后不会继续累积显色。
- 完成后可保存1920×1080光影明信片，含当前照片、章节标题和来源，不含摄像头。
- 菜单卡片随指针轻微倾斜；交互状态提示与手势图例。

v3 已通过本机 Chrome：WebGL 成功初始化、鼠标聚光、暂停冻结进度、两章流程、明信片 PNG 下载、摄像头测试输入下的模型启动。合成的手部关键点验证了双手坐标映射，不能替代真人识别准确性测试。未进行现场真人及公共大屏性能测试。全部仍为本地文件，未上传 GitHub。

## 启动

在本文件所在目录运行：

    python3 -m http.server 8000 --bind 127.0.0.1

打开 http://localhost:8000，点击“开启手势体验”并允许摄像头。模型首次初始化需要等待；没有摄像头可用“鼠标体验”。R 键重置。公网部署必须使用 HTTPS；直接双击 HTML 不适合作为正式运行方式。

## 实现

复用既有项目 ml5.js 手势识别思路，使用本地 MediaPipe Hands WASM 资源。手腕和四个掌指关节的平均位置作为光圈中心，通过指尖与中间关节相对手腕的距离判断张手。坐标镜像映射，低通平滑；失去手势时停止涂抹。Canvas 累积软边蒙版以显示彩色图片，网格估算可见覆盖比例。摄像头仅在浏览器处理，不上传，不录制。网站加载后不依赖远程模型或 CDN。
