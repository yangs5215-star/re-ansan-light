# RE:ANSAN 2.1 — 光迹特效本地版

本项目以用户下载的 V1.2 手势诊断版为基础，保留深色、薄荷绿、16:9 展示区域及时间探索视觉，整合三个地点、真实影像档案、中韩界面、局部环境动态与本地 MediaPipe 手势引擎。

## 运行

在本文件所在目录打开终端：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

用 Chrome 打开 http://127.0.0.1:8000 。也可在 VS Code 中用 Live Server 打开 index.html。请勿直接双击 HTML：ES 模块和摄像头需要本地服务器或 HTTPS。

## 已整合

- 首页使用2026-10-06实际Landsat 8卫星RGB影像，来源USGS／Microsoft Planetary Computer，30米原始分辨率；底图本地保存，无在线地图API依赖。三个按钮按地理范围投影到影像上，标记为地点概略位置，不代表照片机位或导航。
- 每个地点独立影像、时间记录、说明、完成后动态、来源弹窗和记录保存。
- 鼠标、触屏、键盘滑块控制；手掌左右移动控制记录选择。摄像头模式可停留约1.2秒选择按钮。
- 韩文／中文切换；水波、局部反光、芦苇轻摆；可选合成水声。
- 手掌、鼠标或触屏滑动产生薄荷绿发光粒子、局部柔光和消散轨迹；图片切换出现扩散光环。粒子数量上限320，尊重系统“减少动态”设置。
- 进入最后一张图片后停留约1.5秒（至少900毫秒没有明显横向移动），开启局部水波、反光与芦苇动态；不再要求拖到滑块最右端。开始重新探索后退出动态。
- 本地保存识别库、SIMD及非SIMD WASM、手部模型。GPU创建失败会尝试CPU。
- 无账户、无上传接口，不记录摄像头画面或手部数据。

## 修复的确定问题

原 V1.2 中 @mediapipe/tasks-vision@0.10.22 的脚本和 WASM 地址返回404。本项目改为npm注册表验证存在的0.10.21，下载包的SHA-512与注册表完整性字段一致。运行时不依赖jsDelivr、esm.sh或Google模型服务器。

另修复启动取消与资源释放、导航加载竞争、摄像头停止、手掌丢失后的旧坐标残留，加入本地引擎点检与明确错误提示。

## 照片审核：尚未通过教授要求的最终内容验收

程序流程已整合，**不能把它称为已完成同角度生态恢复对照的最终展品**。当前用真实日期的档案选择方式呈现，不伪造连续年份或把不同角度硬叠为同机位转换。

- 始华湖：2011-04-13施工、2018-10-06防潮堤、2025-07-22航拍，拍摄角度不同。
- 芦苇湿地：2013-12-15拍摄记录、2023-11-17官方博客公开资料（拍摄日未确认）、2025-06-21绿色芦苇栈道（作者注明的到访日，无EXIF；文章2025-06-23发布）。末张3000×1687，保留原有水印；只对栈道两侧芦苇添加轻微风动，不扭曲栏杆、游客，不添加并不存在的水面。
- 安山川：2002-12-03施工现场、2015-09-25河道与步道、2024-04-09春日河道。三个拍摄日期均有EXIF依据，来自不同河段而非同机位。

用户随后允许同一明确地点的不同机位，本版据此替换第二、第三案例；不是让不同机位自动配准的变形。2023湿地资料在日期条、节点、来源窗口明确显示“资料公开”，不冒充当年拍摄。第一案例三张图片未改。旧2014修复报道附件EXIF显示2007年，与报道年份不符，未采用。

各地点 data.js 的 pairVerified 当前均为false。后续应替换为有同机位、拍摄年份和许可依据的成对原图，再实现严格配准的扫描揭示。对水面做的是局部照片动态处理，不是实拍视频或水质模拟。没有将现代照片去色后冒充历史照片。

## 验证范围

JavaScript语法、本地资源完整性、鼠标与时间节点、三场景切换、中韩切换、来源与设置、末端停留后动态、本地MediaPipe模型加载与GPU推理会逐项记录于QA.md。摄像头真实手掌追踪尚需用户设备实测；引擎点检不等于摄像头通过。

## 项目文件

- index.html：结构；style.css：原V1.2基础样式；exhibition.css：整合界面。
- app.js：场景与交互；effects.js：粒子与光迹；hand.js：本地手势引擎；data.js：双语、照片日期来源与动态遮罩。
- assets/photos：真实照片；vendor/mediapipe：原始官方库与WASM；models：官方模型。

照片出处、许可、日期依据记录于data.js。含公开再使用许可尚未确认的本地研究照片，未发布到GitHub。Apache-2.0库许可位于vendor/mediapipe/LICENSE；模型来源为Google官方MediaPipe Models（Hand Landmarker float16/1），模型许可需按官方模型卡核对后再公开分发。

官方实现参考：https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js
